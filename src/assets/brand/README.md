# Brand files

Official Hi-School Pharmacy artwork, supplied by the owner. Do not redraw, recolor or re-type it.

- `hsp-badge.png`: the primary badge, red and black on white (transparent background). Used in the header, welcome screen, print pages and PDFs.
- `hsp-badge-gray.png`: alternate with a gray outline (not used by default).
- `hsp-avatar.jpg`: square version for profile pictures (not used by default).

`BrandMark` and `BrandBadge` pick up `hsp-badge.*` and an optional `hsp-icon.*` (the small hex icon) automatically.
Do not use the One-Stop Hardware or Ace Hardware badges in this app.
